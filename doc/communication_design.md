# 组合秤系统通信设计文档 (Modbus RTU Protocol)

本系统由一个 **Master (主控)** 和 **20 个 Slave (称重单元)** 组成，采用标准 **Modbus RTU** 协议进行半双工串行通信。

## 1. 物理层设计
- **传输介质**: RS485 (屏蔽双绞线)
- **拓扑结构**: 手拉手 (Daisy Chain) 总线，末端需 120Ω 终端电阻。
- **波特率**: 115200 bps (推荐提高波特率以降低 20 个节点的轮询延迟)
- **数据位**: 8N1 (8 数据位，无校验，1 停止位)
- **引脚分配**:
  | 设备 | TX | RX | EN (RE/DE) |
  | :--- | :--- | :--- | :--- |
  | **Master** | GPIO 17 | GPIO 16 | GPIO 4 |
  | **Slave** | GPIO 23 | GPIO 22 | GPIO 21 |

## 2. 协议寻址与功能码

### 2.1 站号分配 (Slave ID)
| ID 范围 | 设备类型 | 说明 |
| :--- | :--- | :--- |
| **1 - 20** | 称重单元从机 | 对应 20 个料斗 |
| **21** | 收集传送带电机 | 外部伺服驱动器 |
| **22** | 输出传送带电机 | 外部伺服驱动器 |

### 2.2 支持的功能码
- **0x03 (Read Holding Registers)**: 读取称重数据及状态。
- **0x06 (Write Single Register)**: 发送控制指令（如去皮、开关门）。
- **0x10 (Write Multiple Registers)**: 批量写入参数（如标定值、系数）。

## 3. 寄存器映射表 (Slave ID 1-20)

### 3.1 状态与测量类 (R - 0x03)
| 寄存器地址 | 名称 | 数据类型 | 单位 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **0x0000** | 当前重量 (High) | Float (32-bit) | g | 需连续读取 2 寄存器 |
| **0x0001** | 当前重量 (Low) | ^ | ^ | ^ |
| **0x0002** | 单元状态字 | Uint16 | BIT | 0:准备好, 1:故障, 2:动作中 |
| **0x0003** | 传感器原始值 | Int32 | ADC | 诊断用，需连续读取 2 寄存器 |

### 3.2 命令控制类 (W - 0x06)
| 寄存器地址 | 名称 | 预设值 | 说明 |
| :--- | :--- | :--- | :--- |
| **0x0100** | 通用控制指令 | 1 | **OPEN**: 打开排料门 |
| | | 2 | **CLOSE**: 关闭排料门 |
| | | 3 | **TARE**: 归零/去皮 |
| | | 4 | **CALIBRATE**: 开始标定流程 |

## 4. 核心工作流逻辑

### 4.1 高效轮询 (Polling Sequence)
1. **广播同步 (可选)**: Master 发送广播帧（ID 0）进行全局时间同步（若需要）。
2. **快速获取**: Master 循环对 ID 1~20 发送 `0x03` 指令读取 `0x0000-0x0002`，预计每个节点耗时 10-15ms，总轮询耗时约 200-300ms。

### 4.2 组合排料流程
1. **寻找组合**: 轮询结束，计算最佳组合 ID 列表。
2. **并发执行**:
   - Master 依次向选中的 Slave ID 发送 `0x06 (Address 0x0100)` 写 `1`。
   - 等待 `discharge_time`（约 500ms）。
   - 向对应 ID 发送 `0x06` 写 `2` (Close) 和 `3` (Tare)。
3. **皮带联动**: 同时控制 ID 21/22 伺服电机运行指定步数。

## 5. 错误处理与容错
- **超时识别**: 若探测到 CRC 错误或无响应，主控将该 Slave 状态标记为 `OFFLINE`，不参与下一次组合。
- **看门狗**: Slave 接收到合法指令后重置看门狗，若 10s 无通信则自动关闭排料门进入受控状态。
